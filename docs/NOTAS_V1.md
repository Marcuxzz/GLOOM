# GLOOM v1.0.0 — Windows e Android

**A escuridão começa dentro de você.**

GLOOM é um jogo independente de sobrevivência por ondas ambientado em um sonho, com inimigos que surgem ao redor de uma plataforma no espaço.

## Downloads

- **Windows:** `GLOOM-Windows.zip` — extraia e execute `GLOOM.exe` com `data.win` e `options.ini` na mesma pasta.
- **Android:** `GLOOM-Android.apk` — pacote Android assinado, para dispositivos compatíveis.

A compilação ainda não foi testada nesta sessão em Windows ou Android. A publicação foi preparada com os arquivos enviados pelo desenvolvedor.
