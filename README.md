# GLOOM

> **A escuridão começa dentro de você.**

GLOOM é um jogo independente de sobrevivência por ondas. Em um sonho, o personagem está preso em uma plataforma suspensa no espaço, enquanto criaturas surgem de todos os lados.

O jogo inclui armas, cartas, habilidades, chefes e personalização visual.

## Downloads

As versões públicas de GLOOM para **Windows** e **Android** serão disponibilizadas em [Releases](https://github.com/Marcuxzz/GLOOM/releases).
